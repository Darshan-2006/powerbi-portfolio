# Power Query — Data Cleaning & Transformation

Practice project focused on **Power Query (Get Data)** — cleaning, shaping, and combining data before it reaches the model.

## Files

| File | Description |
|------|-------------|
| `PowerQuery.xlsx` | Cleaned staff dataset (260 rows) — Emp ID, Name, Gender, Department, Salary, Salary Bucket, Start Date |
| `sample-staff-data (1).xlsx` | Raw staff source (276 rows) — includes FTE, Employee type |
| `WebScrapping.xlsx` | Olympic medals data scraped from the web (93 countries) — Rank, Gold, Silver, Bronze, Total |

## Skills Practised
- Importing Excel / web data into Power Query
- Cleaning messy column headers and data types
- Creating derived columns (e.g. Salary Bucket)
- Handling staff attributes (Gender, Department, FTE, Employee type)
- Web scraping into a structured table (medals by country)

## Typical Power Query Steps Demonstrated
1. **Source** → Excel / Web
2. **Promote headers** / rename columns
3. **Change data types**
4. **Filter rows** / remove blanks
5. **Add custom columns**
6. **Close & Apply** into the model

## How to Explore
Open the `.xlsx` files in Excel, or load them into Power BI Desktop via **Get Data → Excel**.
